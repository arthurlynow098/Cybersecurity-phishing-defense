## Sobre o projeto

Material de estudo de segurança com páginas que simulam um fluxo de acesso e scripts PHP de captura. O conteúdo deve ser analisado em laboratório autorizado, com dados fictícios. O nome do repositório não comprova a implementação de mecanismos de defesa.

## Como explorar

Leia os arquivos como material de laboratório. Não utilize credenciais reais; a raiz não fornece um procedimento de instalação ou um ambiente isolado pronto.
